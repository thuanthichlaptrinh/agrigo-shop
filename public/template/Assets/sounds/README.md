# Notification Sounds

Thư mục này chứa các file âm thanh thông báo cho chat.

## Cần thêm file:
- `notification.mp3` - Âm thanh thông báo khi có tin nhắn mới

## Gợi ý:
Bạn có thể tải file âm thanh miễn phí từ:
- https://notificationsounds.com/
- https://freesound.org/
- https://mixkit.co/free-sound-effects/notification/

Đặt tên file là `notification.mp3` và đặt vào thư mục này.
