# Views Laravel - Organic Shop

## 📋 Danh sách View đã tạo

| View                       | Route            | URL             | Mô tả              |
| -------------------------- | ---------------- | --------------- | ------------------ |
| `home.blade.php`           | `home`           | `/`             | Trang chủ          |
| `auth/login.blade.php`     | `login`          | `/login`        | Đăng nhập          |
| `auth/register.blade.php`  | `register`       | `/register`     | Đăng ký            |
| `products.blade.php`       | `products`       | `/products`     | Danh sách sản phẩm |
| `product-detail.blade.php` | `product-detail` | `/product/{id}` | Chi tiết sản phẩm  |
| `cart.blade.php`           | `cart`           | `/cart`         | Giỏ hàng           |
| `checkout.blade.php`       | `checkout`       | `/checkout`     | Thanh toán         |
| `profile.blade.php`        | `profile`        | `/profile`      | Thông tin cá nhân  |

## 🚀 Quick Start

```bash
# Chạy server
php artisan serve

# Truy cập
http://localhost:8000
```

## 📖 Chi tiết

Xem file `HUONG_DAN_TEMPLATE.md` để biết hướng dẫn chi tiết.

## 🔗 Links

-   Trang chủ: http://localhost:8000/
-   Đăng nhập: http://localhost:8000/login
-   Sản phẩm: http://localhost:8000/products
-   Giỏ hàng: http://localhost:8000/cart
